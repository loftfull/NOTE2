# Шлюз (`server.mjs`)

Приложение работает без шлюза: заметки, документы, поиск и — через реестр
моделей — AI живут в браузере. Шлюз нужен для того, чего браузер не может
сделать сам.

| Что даёт шлюз | Почему нельзя в браузере |
|---|---|
| Загрузка по ссылке | нужен доступ к чужому origin и защита от SSRF, которую браузер не даёт |
| Субтитры YouTube | то же самое: CORS запрещает читать страницу видео |
| Аккаунт и синхронизация между устройствами | нужно общее хранилище |
| Ключ провайдера не лежит на устройстве | в APK встроенный ключ извлекается |
| Расшифровка файлов больше одного запроса | нужна докачка по частям |
| Instagram | нужен внешний сборщик |

## Запуск

```bash
npm install
npm run build          # собирает клиент в dist/
npm start              # шлюз на http://0.0.0.0:8787, отдаёт dist/
```

Открыть `http://localhost:8787`. Шлюз отдаёт собранное приложение сам, поэтому
относительные адреса `/api/...` в настройках работают без дополнительной
настройки.

Проверить, что поднялось:

```bash
curl -s http://localhost:8787/api/health | python3 -m json.tool
```

Поле `capabilities` показывает, что реально включено:

```json
{
  "status": "ok",
  "capabilities": {
    "sourceUrl": true, "youtube": true,
    "ai": false, "embed": false, "vision": false,
    "transcribe": false, "instagram": false, "legacySync": false
  }
}
```

`sourceUrl` и `youtube` работают сразу. Остальное включается переменными
окружения ниже. **Ненастроенная возможность отвечает 503 и называет
переменную, которая её включит** — она не подменяет ответ модели ничем
локальным.

## Переменные окружения

### Базовое

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `NOTE2_PORT` | `8787` | порт (`PORT` тоже читается) |
| `NOTE2_HOST` | `0.0.0.0` | адрес прослушивания |
| `NOTE2_STATIC_DIR` | `dist` | где лежит собранный клиент |
| `NOTE2_DATA_DIR` | `.note2-data` | аккаунты, снимки, загрузки |

### Модель, эмбеддинги, распознавание

Один OpenAI-совместимый адрес покрывает Ollama, LM Studio, OpenRouter, Groq,
Mistral и OpenAI.

| Переменная | Пример | Включает |
|---|---|---|
| `NOTE2_AI_BASE_URL` | `http://localhost:11434/v1` | — |
| `NOTE2_AI_API_KEY` | `sk-...` | (пусто для локальных) |
| `NOTE2_AI_MODEL` | `qwen2.5:7b` | `/api/ai` |
| `NOTE2_EMBED_MODEL` | `nomic-embed-text` | `/api/embed` |
| `NOTE2_VISION_MODEL` | `qwen2.5-vl:7b` | `/api/vision` |

Полностью локальный вариант через Ollama:

```bash
NOTE2_AI_BASE_URL=http://localhost:11434/v1 \
NOTE2_AI_MODEL=qwen2.5:7b \
NOTE2_EMBED_MODEL=nomic-embed-text \
npm start
```

### Расшифровка

| Переменная | Пример |
|---|---|
| `NOTE2_TRANSCRIBE_BASE_URL` | `https://api.openai.com/v1` |
| `NOTE2_TRANSCRIBE_API_KEY` | `sk-...` (если не задан — берётся `NOTE2_AI_API_KEY`) |
| `NOTE2_TRANSCRIBE_MODEL` | `whisper-1` |

Шлюз запрашивает `response_format=verbose_json`: без него не будет таймкодов,
а значит цитата не сможет указать на момент в записи.

### Аккаунты

| Переменная | Что делает |
|---|---|
| `NOTE2_REGISTRATION_TOKEN` | регистрация разрешена только с этим токеном |
| `NOTE2_ALLOW_OPEN_REGISTRATION=1` | регистрация открыта всем |
| `NOTE2_SYNC_TOKEN` | включает старый режим синхронизации (без аккаунтов) |
| `NOTE2_TRUST_PROXY=1` | брать адрес клиента из `X-Forwarded-For` |

`NOTE2_TRUST_PROXY` ставится **только** если перед шлюзом стоит обратный
прокси, который этот заголовок перезаписывает. Без прокси доверие к нему
означает, что ограничение попыток входа обходится одной строкой в запросе:
заголовок подделывает кто угодно.

**Регистрация закрыта, пока не задано одно из первых двух.** Шлюз, доступный из
интернета, иначе молча накапливает чужие аккаунты.

### Instagram

| Переменная | Что делает |
|---|---|
| `NOTE2_INSTAGRAM_COMMAND` | команда, которой передаётся ссылка на пост и которая печатает JSON в stdout |

Шлюз **не** содержит сборщика Instagram и не обходит ограничения площадки. Он
запускает то, что укажет владелец, без shell и только после проверки, что
ссылка ведёт на пост instagram.com. Ожидаемый JSON:

```json
{
  "shortcode": "Cabc123",
  "caption": "текст поста",
  "owner": { "username": "автор", "fullName": "Имя" },
  "type": "carousel",
  "media": [{ "kind": "image", "url": "https://...", "width": 1080, "height": 1080 }]
}
```

### Лимиты

| Переменная | По умолчанию |
|---|---|
| `NOTE2_MAX_URL_BYTES` | 8 МБ |
| `NOTE2_MAX_UPLOAD_BYTES` | 24 МБ (один запрос; докачкой — до 32× больше) |
| `NOTE2_MAX_VISION_BYTES` | 18 МБ |
| `NOTE2_MAX_SNAPSHOT_BYTES` | 64 МБ |
| `NOTE2_REQUEST_TIMEOUT_MS` | 20 000 |
| `NOTE2_UPSTREAM_TIMEOUT_MS` | 120 000 |

## Маршруты

| Метод и путь | Назначение |
|---|---|
| `GET /api/health` | состояние и список включённых возможностей |
| `POST /api/source-url` | загрузка страницы по ссылке |
| `POST /api/youtube` | метаданные видео и субтитры |
| `POST /api/ai` | текстовая задача к модели |
| `POST /api/embed` | эмбеддинги для векторного поиска |
| `POST /api/vision` | распознавание текста на изображении |
| `POST /api/transcribe` | расшифровка аудио/видео одним запросом |
| `POST /api/uploads/init` | начать докачиваемую загрузку |
| `PUT /api/uploads/:id/chunks/:index` | передать фрагмент |
| `POST /api/uploads/:id/transcribe` | расшифровать собранный файл |
| `GET /api/uploads/:id` | состояние загрузки |
| `DELETE /api/uploads/:id` | удалить загрузку |
| `POST /api/account/register` · `/login` · `/logout` | аккаунт |
| `GET /api/account/me` · `/sessions` | аккаунт и устройства |
| `DELETE /api/account/sessions/:id` | отозвать сессию устройства |
| `GET`/`PUT` `/api/account/sync/:workspaceId` | синхронизация |
| `GET`/`PUT` `/api/sync/:workspaceId` | старый режим синхронизации |
| `POST /api/instagram` | архивировать пост |
| `GET /api/instagram/:shortcode/media/:index` | архивное медиа |

Любой ответ — JSON, включая ошибки: `{"error": "..."}`. Неизвестный путь под
`/api/` отвечает JSON-ошибкой 404, а не страницей приложения. Это не
формальность: отдача `index.html` на промах API — ровно то, что приходило
пользователю как `Unexpected token '<', '<!doctype...'`.

## Что шлюз делает для безопасности

**Загрузка по ссылке.** Адрес проверяется трижды: литеральный частный адрес
отклоняется сразу; имя, которое резолвится в частный диапазон, отклоняется при
подключении; проверка выполняется внутри резолвера сокета, поэтому
подтверждённый адрес — это тот же адрес, к которому идёт подключение (иначе
между проверкой и подключением остаётся окно для DNS rebinding). Перенаправления
идут вручную: каждый переход — новый недоверенный URL и проходит те же три
проверки. Список заблокированных диапазонов включает loopback, RFC1918,
link-local (в том числе `169.254.169.254`), CGNAT, multicast, зарезервированные,
а также их формы через IPv4-mapped IPv6, NAT64 и 6to4.

**Ограничение размера** считается по фактически прочитанным байтам, а не по
заголовку `Content-Length`, который сервер может занизить или не прислать.

**Ответ не-JSON от провайдера** сообщается по статусу и типу; тело уходит в лог
сервера, а не пользователю.

**Непредвиденная ошибка** отвечает общим текстом. Сообщения, написанные для
человека, доходят целиком — включая имя переменной, которую надо задать. А вот
текст случайной ошибки рантайма писал не автор шлюза: «Не удалось прочитать
/tmp/note2-data/accounts.json: Expected property name...» раскрывает раскладку
файловой системы, ОС и каталог установки. Такие ответы заменяются общим
сообщением, настоящая ошибка со стеком уходит в журнал.

**Пароли** — scrypt. Токен сессии хранится как SHA-256 от секрета, сравнение —
постоянного времени.

**Вход отвечает одинаково** на неизвестный адрес и на неверный пароль — и
одинаково по времени. Одного сообщения мало: пока при отсутствии аккаунта
scrypt не считался, ответ приходил за 2.2 мс против 45.3 мс, и время само
выдавало, какие адреса зарегистрированы. Теперь scrypt считается всегда —
для несуществующего аккаунта против подставной записи, результат
отбрасывается. Замер после правки: ×1.0.

**Попытки входа ограничены**: 8 неудач за 15 минут с одной пары «адрес
клиента + почта» дают блокировку на 15 минут и ответ 429 с `Retry-After`.
Ключ — пара, а не что-то одно: только по IP один NAT наказывал бы всех за
ним, только по почте кто угодно блокировал бы чужой вход. Удачный вход
снимает накопленное. Перебор токена регистрации ограничен так же — защищать
его больше нечем.

**Конфликт синхронизации** — 409 с номером текущей ревизии, а не перезапись.

**Снимок** очищается от токенов синхронизации перед сохранением: он несёт весь
объект настроек, и хранить на сервере токен чужого устройства нельзя.

## Тесты

```bash
npm test
```

Тесты шлюза поднимают настоящие сокеты и настоящий процесс: мок-провайдер
OpenAI-совместимого API записывает, что ему прислали; проверки docker-подобных
сценариев (перезапуск во время расшифровки, одновременная запись с двух
устройств, обрыв фрагмента) выполняются на реальной файловой системе.
