# NOTE2 v4.9 — Interactive application contract

1. v4.0 remains the visual baseline.
2. On mobile the redundant global sticky header is hidden. Primary page content starts near the top edge with only normal content padding.
3. Every element styled as an object/action must either work or be visibly disabled.
4. Notes: create, open, edit, autosave, pin, favorite, tag and delete.
5. Tasks: create, toggle and delete.
6. Sources: add by file/link/share, filter/search, open in Source Viewer.
7. Search: result click returns to exact note/source/evidence.
8. Profile: name/theme/text-size/density are editable and persisted immediately.
9. Capture remains the single intake for note/task/media/document/link.
10. No provider-specific top-level tabs are permitted.
