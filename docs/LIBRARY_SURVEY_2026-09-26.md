# Разбор готовых решений — 2026-09-26

Что можно взять готовым, чтобы усилить приложение, и чего это будет стоить.

## Как это проверялось, и чего проверить не удалось

**GitHub напрямую закрыт.** Прокси сессии перехватывает `api.github.com` и
отдаёт 403 на всё, кроме `loftfull/NOTE2`:

```
{"message":"GitHub access to this repository is not enabled for this session."}
```

Поэтому **звёзд, даты последнего коммита и числа открытых issues здесь нет** —
я не смог их получить и не стану приводить по памяти: мой обучающий срез —
май 2026, и цифры такого рода устаревают быстрее всего.

**Что проверено:** реестр npm (`registry.npmjs.org` отвечает) — версия,
лицензия, дата публикации, число зависимостей, размер пакета. Дата публикации
заодно показывает, жив ли проект.

**Что измерено:** реальный прирост к сборке. Не «по описанию», а сборкой
минимального входа этим же Vite 8: база с React, затем то же плюс библиотека,
разница в gzip.

## Рекомендации

### 1. Рендер Markdown — сделано в этом проходе

**Пробел, который это закрывает, — настоящая дыра, а не улучшение.** В
редакторе шесть кнопок: «Заголовок», «Чек-лист», «Список», «Цитата», «Код»,
«Таблица». Все вставляют Markdown. Показывать его было нечем: заметка везде
отображалась как обычный текст, а в превью разметка просто стиралась —
`stripMarkdown` вырезает `#*_`>~-` как мусор. Приложение предлагало писать в
формате, который само не умело читать.

`marked` + `dompurify`, +23.3 КБ.

Почему санитайзер обязателен, а не «на всякий случай»: текст заметки приходит
не только от владельца — из импортированных файлов, страниц по ссылке,
субтитров YouTube и ответов модели. Результат уходит в
`dangerouslySetInnerHTML` в приложении, где рядом лежат ключи провайдеров.
15 тестов, больше половины — на XSS. Проверено в браузере: `<script>` вырезан,
`javascript:` в ссылке обезврежен, внешние ссылки открываются с
`rel="noopener noreferrer"`.

### 2. OCR без сервера — `tesseract.js`

**Самый крупный выигрыш по возможностям из оставшихся.** Сейчас распознавание
изображений требует шлюза, vision-модели и ключа. `tesseract.js` делает это в
браузере: без сервера, без ключа, без оплаты за страницу.

Цена честная и её надо знать заранее:

- **к сборке +7 КБ** — это тонкая обёртка;
- **в рантайме 3–4 МБ WASM-ядра**: в пакете `tesseract.js-core` лежит 44 МБ
  вариантов, из которых берётся один;
- **плюс языковые данные.** Их размер для русского **я не смог измерить** —
  `cdn.jsdelivr.net` в этом окружении закрыт (HTTP 000);
- по умолчанию и ядро, и языки качаются с CDN. Для офлайн-приложения их надо
  положить рядом с собой, и это добавит несколько мегабайт к ассетам.

Решение стоит принимать сознательно: это офлайн-OCR ценой заметного веса.

### 3. Анимации — `motion`

Прямо отвечает на «хочется, чтобы приложение было интерактивным,
анимационным».

Брать **императивный `animate`, а не компоненты**: +18.2 КБ против +38.8 КБ.
Разница вдвое, а нужного тут хватает — переходы между экранами, появление
шторки, отклик на нажатие. Компонентный API окупается там, где анимация
управляется состоянием во многих местах; у нас это не так.

Обязательное условие: `prefers-reduced-motion` уже соблюдается в стилях, и
новые анимации должны его соблюдать тоже.

### 4. Виртуализация списка — `@tanstack/react-virtual`, +7.2 КБ

Список заметок рисует все строки сразу. На 40 заметках это 4221 px прокрутки —
терпимо. На тысяче станет заметно. Брать **когда появятся сотни заметок**, а
не сейчас: 7 КБ за решение проблемы, которой пока нет.

### 5. Полнотекстовый индекс — `minisearch`, +5.3 КБ

Сейчас поиск линейно перебирает заметки и фрагменты, приводя слова к основам
стеммером Snowball. Работает и покрыто тестами. `minisearch` даст префиксный
поиск, опечатки и ранжирование по BM25.

**Не срочно.** Выигрыш появляется на объёме, а стеммер придётся сохранить —
своей морфологии для русского в `minisearch` нет.

### 6. Чего брать не стоит

| | почему |
|---|---|
| `@huggingface/transformers` | 9.43 МБ пакет плюс веса моделей. Дал бы эмбеддинги без ключа, но для телефона это неподъёмно |
| `yjs` | CRDT решает задачу совместного редактирования, а у нас синхронизация одного человека между своими устройствами. Конфликт ревизий с понятным сообщением честнее молчаливого слияния |
| `dexie` | хранилище написано вручную, работает и покрыто 12 тестами, включая миграции. Менять рабочий слой данных ради удобства API — риск без выигрыша |
| `vaul` | шторка уже есть и решает известную ловушку: `backdrop-filter` у предка делает его containing block для `position: fixed`, поэтому шторка рендерится через портал. Последняя публикация — декабрь 2024 |
| `cmdk`, `sonner`, `embla` | командная палитра, уведомления и карусель уже написаны и работают. Замена ради замены |

## Порядок, если брать

1. **Markdown** — закрывает дыру, а не добавляет украшение. *Сделано.*
2. **`tesseract.js`** — снимает зависимость от сервера с целой функции. Решение
   про вес принимает владелец.
3. **`motion`** — прямо отвечает на просьбу про интерактивность.
4. **Виртуализация и индекс** — когда появится объём.
