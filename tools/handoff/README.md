# Передача работы: чем собирать

Четыре инструмента. Все запускаются из корня репозитория.

| команда | что делает |
|---|---|
| `npm run handoff:state` | пересобирает `docs/handoff-state.json`: версии, ветка, число тестов (прогоняет их), результат сборки, объём кода, схема хранения, известные пробелы |
| `npm run handoff:bundle` | архив `.tar.gz` через `git archive` — для человека или для загрузки в репозиторий |
| `npm run handoff:pack -- <куда>` | текстовые сборки для чат-интерфейса: бриф, задание, снимок, код — в `.md` и `.txt`, с измеренным размером в токенах |
| `npm run handoff:pdf -- <файл.md> <файл.pdf>` | PDF из разметки, если интерфейс принимает документ, но не текст |
| `npm run handoff:images -- <файл.md> <каталог> [префикс]` | страницы PNG, если интерфейс принимает **только изображения** |

## Почему форматов несколько

Архив годится человеку и не годится чату: приложить `.tar.gz` почти нигде
нельзя. Поэтому `pack` раскладывает то же содержимое в простые текстовые
файлы разного объёма — чтобы выбрать под ограничение конкретного
интерфейса, а не гадать.

Размер в токенах измеряется настоящим токенизатором
(`gpt-tokenizer`, словарь `o200k_base`), если он установлен:
`npm i --no-save gpt-tokenizer`. Без него выводится только размер в
символах. Оценок «на глаз» здесь нет.

У других моделей число токенов отличается — обычно в пределах пятой части,
потому что словари разные. Для русского текста разброс больше, чем для
кода: кириллица в словарях OpenAI кодируется плотнее, чем во многих других.

## Что чем собрано

`bundle.mjs` использует `git archive`, а не копирование списка каталогов.
Первая версия собиралась вручную и потеряла `scripts/` вместе с корневыми
модулями: в распакованном виде падало семь файлов тестов из тридцати двух.
`git archive` берёт индекс целиком и забыть ничего не может.

`pdf.mjs` переводит разметку в HTML тем же `marked`, что и приложение, и
печатает предустановленным Chromium. Санитайзер здесь не нужен: на вход
идёт собственный файл проекта, а не чужой ввод. Нужен Playwright:
`npm i --no-save playwright`.

## Когда принимают только картинки

Такие интерфейсы есть: список разрешённых расширений состоит из `png`,
`jpg`, `jpeg`, `webp` и их синонимов. Тогда `handoff:images` печатает
разметку страницами PNG.

Что при этом надо понимать. Текст перестаёт быть текстом: модель читает
его зрением, а зрение ошибается. Для прозы это приемлемо, для кода — нет,
потому что в коде значим каждый знак. Поэтому:

- **описание проекта** в картинках отдавать можно: 7 страниц;
- **код** — не стоит. Набор ключевых модулей занимает 59 страниц и 16 МБ,
  и за точность распознавания никто не отвечает. Код берётся из
  репозитория.

Параметры страницы подобраны под чтение зрением: ширина 1400 px при кегле
23 px, обычная плотность (не удвоенная — её всё равно уменьшат при
отправке), перекрытие 60 px, чтобы строка, разрезанная границей, целиком
попала на следующую страницу. Формат PNG, а не JPEG: на сжатии с потерями
текст расползается.

Проверено чтением: страницы прочитаны зрением модели целиком, включая
inline-код, шестнадцатеричные цвета и значения контраста.

Плотность можно изменить переменной `NOTE2_PAGE_SCALE` — например `2` даёт
страницы вдвое крупнее и файлы втрое тяжелее.
