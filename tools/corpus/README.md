# Корпус настоящих медиафайлов

Проверка разбора на файлах, сделанных не здесь. Набор в
`test/fixtures/files` собран этим проектом и потому предсказуем; чужие
файлы ловят то, чего свой набор не поймает: сломанные заголовки, редкие
кодировки, пустые документы, экзотические контейнеры.

## Откуда файлы

Общий интернет из этого контейнера закрыт. Прокси отвечает 403 на CONNECT
к любому хосту вне реестров пакетов — проверено на
`upload.wikimedia.org`, `archive.org`, `www.w3.org`, `filesamples.com`,
`sample-videos.com`, `file-examples.com`, `commons.wikimedia.org`; тот же
отказ виден в `recentRelayFailures` у самого прокси. Открыты только
`registry.npmjs.org`, `jsr.io`, `pypi.org`, `files.pythonhosted.org`,
`index.crates.io`, `proxy.golang.org`.

Поэтому корпус взят из тестовых наборов чужих проектов, опубликованных на
PyPI. Это настоящие файлы настоящих кодировщиков, просто доставленные
через единственный доступный канал.

| пакет | версия | что даёт |
|---|---|---|
| `pillow` | 12.3.0 | 435 PNG, 77 TIF, 74 BMP, 65 JPG, 43 GIF, 36 WebP, 29 TIFF, 15 AVIF, 11 ICO, 8 SVG, 2 PDF |
| `mutagen` | 1.48.1 | 21 MP3, 9 FLAC, 4 WMA, 4 M4A, 3 WAV, 3 OGG, 2 AAC, 1 Opus, 2 MP4 |
| `python-docx` | 1.2.0 | 47 документов Word |
| `moviepy` | 2.2.1 | MP4, GIF, JPEG |

Итого 902 файла, около 40 МБ. В репозиторий корпус не кладётся: он
великоват и принадлежит чужим проектам со своими лицензиями. Скрипт
скачивает его заново.

## Как прогнать

```
node tools/corpus/fetch.mjs                     # скачать и распаковать
node tools/corpus/probe.mjs                     # прогнать через inferKind и parseLocalFile
node tools/corpus/probe.mjs --no-type           # то же, но File.type пустой
```

Второй прогон — не придирка. `File.type` приходит пустым при выборе через
Android SAF, у части облачных провайдеров файлов и при перетаскивании из
некоторых приложений. Именно он нашёл главный дефект: вид медиа
определялся только по типу, и без него любая фотография становилась
«неизвестным двоичным форматом» — а значит, не попадала в распознавание,
потому что `importFiles` зовёт коннектор только для `image`, `audio` и
`video`.

Выводы корпуса закреплены в `test/kind-detection.test.mjs`; он работает
без скачивания.
